# 視覺化設計器操作手冊 (User Guide)

本文檔為 **Avalonia Form Generator (AFG)** 的完整使用者操作指南，包含畫布互動、裝置解析度設定、屬性檢查、MVVM 綁定配置與跨平台多專案匯出流程。

---

## 1. 介面工作區佈局 (Workspace Layout)

啟動 AFG 後，介面主要分為五大區域：

```text
+---------------------------------------------------------------------------------------------------------------+
| 頂部工具列: [新增] [開啟] [儲存] [匯出整包專案] | [加入控制項] [刪除] [網格吸附] | [解析度: 9:19.5] [寬: 390] [高: 844] [行動端] | [複製 View] [複製 VM] |
+------------------+----------------------------------------------------------------------------+---------------+
| 左側邊欄          | 中央畫布區                                                                  | 右側邊欄      |
| [工具箱]         |                                                                            | [屬性檢查器]  |
| - 常用控制項     |  +---------------------------------------------------------------------+   | - 外觀        |
| - 佈局容器       |  |                                                                     |   | - 排版        |
|                  |  |                     [ 設計畫布 (Design Canvas) ]                    |   | - 資料綁定    |
| [元件樹]         |  |                                                                     |   | - 事件命令    |
| - 階層式節點     |  +---------------------------------------------------------------------+   |               |
|                  | -------------------------------------------------------------------------- |               |

+------------------+----------------------------------------------------------------------------+---------------+
| 底部狀態列: 目前選取節點 ID | 語法診斷狀態                                                                      |
+---------------------------------------------------------------------------------------------------------------+
```

## 2. 操作步驟說明 (Step-by-Step Instructions)

### 2.1 裝置解析度與長寬比配置
在頂部工具列中央：
1. **預設解析度切換**：下拉選單提供多種主流規格：
   - `Phone 9:19.5 (Modern Flagship)` (390 x 844)
   - `Phone 9:20 (Android Standard)` (412 x 915)
   - `Phone 9:16 (Classic Mobile)` (360 x 640)
   - `Phone FHD+ 9:20` (1080 x 2400)
   - `Tablet 3:4 (iPad Standard)` (768 x 1024)
   - `Tablet 16:10` (800 x 1280)
   - `Desktop 1080p / 720p / Standard`
2. **自訂解析度輸入**：直接在「寬:」與「高:」數值框輸入任意像素數值（如 iPhone 16 Pro Max `430 x 932` 或折疊螢幕尺寸），畫布將即時自適應調整。
3. **跨平台行動端開關**：勾選「包含行動端 (.Android)」可在匯出時同時生成 Android 宿主專案。

### 2.2 新增控制項到畫布
1. 在左側 **「工具箱」** 中瀏覽或透過搜尋列輸入關鍵字（例如 `Button`, `TextBox`）。
2. 選中該控制項項目。
3. 點選頂部工具列的 **「加入控制項」** 按鈕，控制項即會自動加入畫布並自動對齊網格。

### 2.3 畫布控制項選取、移動與縮放
- **選取控制項**：以滑鼠左鍵點選畫布上的任何控制項，控制項周圍將出現藍色選取外框與 **8 個白色調整手柄**。
- **移動位置**：在選取的控制項內部按住滑鼠左鍵並拖曳，即可改變其 X (CanvasLeft) 與 Y (CanvasTop) 座標。
- **縮放尺寸**：拖曳 8 個手柄中的任一控制點（四個角落或四個邊緣）即可即時調整寬度與高度。
- **對齊輔助線 (Snapping)**：當控制項邊界或中心點接近其他控制項或網格時，畫面會出現青色虛線輔助線並自動吸附。
- **刪除控制項**：選取控制項後，點選工具列的 **「刪除」** 按鈕。

### 2.4 設定控制項屬性與外觀
在右側 **「屬性檢查器」** 的 **「外觀」** 與 **「排版」** 分頁中：
- 修改 **控制項名稱 (x:Name)**（例如 `submitButton`，需符合 C# 識別碼規範）。
- 修改 **內容 (Content)** 或 **文字 (Text)**（例如按鈕標題、標籤文字）。
- 設定 **提示文字 (Watermark)**（針對文字輸入框）。
- 調整 **水平/垂直對齊方式**、**外距 Margin**（左、上、右、下四邊數值）與 **不透明度 Opacity**。

### 2.5 配置 MVVM 資料綁定 (Binding Builder)
1. 在右側屬性檢查器切換至 **「資料綁定」** 分頁。
2. 點選 **「新增資料綁定」**。
3. 設定：
   - **View 屬性**：欲綁定的 View 控制項屬性（例如 `Text`, `IsEnabled`, `IsChecked`, `Value`, `Width`, `Height`）。
   - **ViewModel 屬性名稱**：對應的 ViewModel 屬性名稱（例如 `Username`, `CanSubmit`）。
   - **綁定模式 (Mode)**：選擇 `TwoWay`（雙向）、`OneWay`（單向）或 `Default`。
4. 畫布底部的 **ViewModel (CommunityToolkit.Mvvm)** 預覽會自動生成：
   ```csharp
   [ObservableProperty]
   private string _username = string.Empty;
   ```

### 2.6 配置事件轉命令 (Event-to-Command Mapping)
1. 切換至 **「事件命令」** 分頁。
2. 點選 **「新增事件命令」**。
3. 輸入事件名稱（例如 `Click`, `Tapped`）與對應的 Command 名稱（例如 `SubmitOrderCommand`）。
4. 程式碼生成器會自動在 ViewModel 中生成帶有 `[RelayCommand]` 的方法：
   ```csharp
   [RelayCommand]
   private void SubmitOrder()
   {
       // TODO: 實作命令業務邏輯
   }
   ```

### 2.7 即時預覽與跨平台方案匯出
- **單檔代碼複製**：在中央底部代碼預覽區可直接檢視 Roslyn 格式化後的 C# 代碼，點選工具列的 **「複製 View C#」** 或 **「複製 ViewModel C#」** 即可將代碼貼入現有專案。
- **專案檔儲存/開啟**：點選 **「儲存」** 將當前畫布狀態儲存為 `.afg.json` 檔案；後續可透過 **「開啟」** 重新載入。
- **一鍵匯出跨平台專案**：點選 **「匯出整包專案」** 並選擇目標資料夾，系統會自動生成包含：
  - `.slnx` Visual Studio 2022+ 現代化解決方案檔
  - `src/{Project}.Shared/`（包含 `App.cs` DI 容器、`Config.cs`、`GlobalUsings.cs`、`AvaloniaMarkupExtensions.cs`、`Services/`、`ViewModels/`、`Views/`）
  - `src/{Project}.Desktop/`（桌面端載入點 `Program.cs`，啟動視窗預設最大化）
  - `src/{Project}.Android/`（行動端 Android 宿主專案，若有勾選行動端）
  可直接以 Visual Studio 2022/2026 開啟或執行 `dotnet build` 秒級編譯！
