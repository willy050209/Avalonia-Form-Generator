# 視覺化設計器操作手冊 (User Guide)

本文檔為 **Avalonia Form Generator (AFG)** 的完整使用者操作指南，包含畫布互動、屬性檢查、MVVM 綁定配置與專案匯出流程。

---

## 1. 介面工作區佈局 (Workspace Layout)

啟動 AFG 後，介面主要分為五大區域：

```
+-----------------------------------------------------------------------------------+
| 頂部工具列: [新增] [開啟] [儲存] [匯出整包專案] | [➕加入] [🗑️刪除] [🧲吸附] | [📋複製] |
+------------------+----------------------------------------------+-----------------+
| 左側邊欄          | 中央畫布區                                    | 右側邊欄        |
| [🧰 工具箱]      |                                              | [🔍 屬性檢查器]  |
| - 常用控制項     |  +---------------------------------------+   | - 🎨 外觀       |
| - 佈局容器       |  |                                       |   | - 📐 排版       |
|                  |  |         [ 設計畫布 (Canvas) ]         |   | - 🔗 綁定       |
| [🌳 DOM 元件樹]  |  |                                       |   | - ⚡ 事件       |
| - 階層式節點     |  +---------------------------------------+   |                 |
|                  | -------------------------------------------- |                 |
|                  | 底部即時程式碼預覽: [📄 View] [⚙️ ViewModel]   |                 |
+------------------+----------------------------------------------+-----------------+
| 底部狀態列: 目前選取節點 ID | 語法驗證狀態                                         |
+-----------------------------------------------------------------------------------+
```

## 2. 操作步驟說明 (Step-by-Step Instructions)

### 2.1 新增控制項到畫布
1. 在左側 **「🧰 工具箱」** 中瀏覽或透過搜尋列輸入關鍵字（例如 `Button`, `TextBox`）。
2. 選中該控制項項目。
3. 點選頂部工具列的 **「➕ 加入控制項」** 按鈕，控制項即會自動加入畫布並自動對齊網格。

### 2.2 畫布控制項選取、移動與縮放
- **選取控制項**：以滑鼠左鍵點選畫布上的任何控制項，控制項周圍將出現藍色選取外框與 **8 個白色調整手柄**。
- **移動位置**：在選取的控制項內部按住滑鼠左鍵並拖曳，即可改變其 X (CanvasLeft) 與 Y (CanvasTop) 座標。
- **縮放尺寸**：拖曳 8 個手柄中的任一控制點（四個角落或四個邊緣）即可即時調整寬度與高度。
- **對齊輔助線 (Snapping)**：當控制項邊界或中心點接近其他控制項或網格時，畫面會出現青色虛線輔助線並自動吸附。
- **刪除控制項**：選取控制項後，點選工具列的 **「🗑️ 刪除」** 按鈕。

### 2.3 設定控制項屬性與外觀
在右側 **「🔍 屬性檢查器」** 的 **「🎨 外觀」** 與 **「📐 排版」** 分頁中：
- 修改 **控制項名稱 (x:Name)**（例如 `submitButton`，需符合 C# 識別碼規範）。
- 修改 **內容 (Content)** 或 **文字 (Text)**（例如按鈕標題、標籤文字）。
- 設定 **提示文字 (PlaceholderText)**（針對文字輸入框）。
- 調整 **水平/垂直對齊方式**、**外距 Margin**（左、上、右、下四邊數值）與 **不透明度 Opacity**。

### 2.4 配置 MVVM 資料綁定 (Binding Builder)
1. 在右側屬性檢查器切換至 **「🔗 綁定」** 分頁。
2. 點選 **「➕ 新增資料綁定」**。
3. 設定：
   - **View 屬性**：欲綁定的 View 控制項屬性（例如 `Text`, `IsEnabled`, `IsChecked`, `Value`）。
   - **ViewModel 屬性名稱**：對應的 ViewModel 屬性名稱（例如 `Username`, `CanSubmit`）。
   - **綁定模式 (Mode)**：選擇 `TwoWay`（雙向）、`OneWay`（單向）或 `Default`。
4. 畫布底部的 **ViewModel (CommunityToolkit.Mvvm)** 預覽會自動生成：
   ```csharp
   [ObservableProperty]
   private string _username = string.Empty;
   ```

### 2.5 配置事件轉命令 (Event-to-Command Mapping)
1. 切換至 **「⚡ 事件」** 分頁。
2. 點選 **「➕ 新增事件命令」**。
3. 輸入事件名稱（例如 `Click`, `Tapped`）與對應的 Command 名稱（例如 `SubmitOrderCommand`）。
4. 程式碼生成器會自動在 ViewModel 中生成帶有 `[RelayCommand]` 的方法：
   ```csharp
   [RelayCommand]
   private void SubmitOrder()
   {
       // TODO: 實作命令業務邏輯
   }
   ```

### 2.6 即時預覽與專案匯出
- **單檔代碼複製**：在中央底部代碼預覽區可直接檢視 Roslyn 格式化後的 C# 代碼，點選工具列的 **「📋 複製 View C#」** 或 **「📋 複製 ViewModel C#」** 即可將代碼貼入現有專案。
- **專案檔儲存/開啟**：點選 **「💾 儲存」** 將當前畫布狀態儲存為 `.afg.json` 檔案；後續可透過 **「📂 開啟」** 重新載入。
- **一鍵匯出整包專案**：點選 **「🚀 匯出整包專案」** 並選擇目標資料夾，系統會自動生成包含 Visual Studio 現代化方案檔 (`.slnx`)、專案檔 (`.csproj`)、`Program.cs`、`App.axaml`、`View.cs`、`ViewModel.cs`、`.editorconfig` 與 `.gitignore` 的獨立專案，可直接以 Visual Studio 2022/2026 或 `dotnet build` 開啟編譯！
