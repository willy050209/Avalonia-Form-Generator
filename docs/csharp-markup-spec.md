# C# Declarative Markup 生成語法規範 (C# Markup Spec)

本文檔說明 AFG 所產出的純 C# 宣告式 UI（C# Markup / Declarative C# UI）的鏈式語法規則、資料綁定表達式與 ViewModel 生成規範。

---

## 1. View 生成語法規則 (C# Markup Syntax)

AFG 將 UI AST 轉譯為純 C# 的宣告式結構，具備高型別安全性、IDE 完整導航 (F12) 與 重構支援。

### 1.1 基本鏈式調用結構 (Fluent Chaining)
```csharp
Content = new Canvas()
    .Width(800)
    .Height(600)
    .Children(
        new Button()
            .Width(120)
            .Height(35)
            .CanvasLeft(100)
            .CanvasTop(50)
            .Content("確認送出")
            .HorizontalAlignment(HorizontalAlignment.Center)
            .Margin(new Thickness(10, 5, 10, 5))
    );
```

### 1.2 屬性轉譯對照表

| AST 屬性類型 | C# Markup 轉譯語法 | 說明 |
| :--- | :--- | :--- |
| **幾何尺寸** | `.Width(300).Height(40)` | 直接轉譯為擴充方法調用。 |
| **邊距內外距** | `.Margin(new Thickness(10, 5, 10, 5))` | 支援四邊獨立設定。 |
| **列舉值屬性** | `.HorizontalAlignment(HorizontalAlignment.Center)` | 自動補齊完整的列舉命名空間。 |
| **附屬座標屬性** | `.CanvasLeft(100).CanvasTop(50)` | 自動轉為 Canvas 附加屬性。 |
| **Grid 網格配置** | `.GridRow(1).GridColumn(0).GridRowSpan(2)` | 轉為 Grid 列欄定位。 |
| **Grid 尺寸定義** | `.RowDefinitions("Auto", "*")` | 支援 Auto、Star 與固定像素長度。 |
| **雙向資料綁定** | `.Text(nameof(MyViewModel.Username), BindingMode.TwoWay)` | 生成強型別 nameof 綁定。 |
| **事件轉命令** | `.Command(nameof(MyViewModel.SubmitCommand))` | 自動將 Click 等事件映射至 ViewModel RelayCommand。 |
| **容器子節點** | `.Children( new Button(), new TextBox() )` | 遞迴遍歷子節點並插入縮排陣列。 |

## 2. ViewModel 生成規範 (CommunityToolkit.Mvvm)

AFG 的 ViewModel 生成器嚴格遵循 `CommunityToolkit.Mvvm` 原始碼生成器標準：

1. **類別宣告**：宣告為 `public partial class <Name>ViewModel : ObservableObject`。
2. **屬性生成**：
   - 根據綁定目標自動推斷型別（例如 `IsChecked` -> `bool`, `Value` -> `double`, `Text` -> `string`）。
   - 欄位加上 `[ObservableProperty]`，採用下劃線駝峰命名（如 `_username`），原始碼生成器會自動擴展為公開屬性 `Username`。
3. **命令生成**：
   - 映射的方法加上 `[RelayCommand]`，自動去除 "Command" 後綴作為方法名（如 `SubmitOrderCommand` -> `void SubmitOrder()`）。

### 範例 ViewModel 產出
```csharp
// <auto-generated />
#nullable enable

using System;
using CommunityToolkit.Mvvm.ComponentModel;
using CommunityToolkit.Mvvm.Input;

namespace GeneratedApp.Views;

public partial class MainFormViewModel : ObservableObject
{
    [ObservableProperty]
    private string _username = string.Empty;

    [ObservableProperty]
    private bool _isAdmin;

    [RelayCommand]
    private void Login()
    {
        // TODO: 實作命令業務邏輯
    }
}
```
